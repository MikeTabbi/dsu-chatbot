Delaware State University (chat assistant demo)

DSU chat assistant demo

This page loads the chat widget the same way desu.edu would: one script tag. Open the chat in the bottom-right corner and ask a question, for example "Which dorms have carpeted rooms?" or "How do I apply for housing?".

Answers come from the backend on http://localhost:8000, which searches DSU's website content and asks Claude to answer from it. Start both with ./scripts/run-demo.sh (see widget/README.md). To try the widget without the backend, open demo.html?mock=1.

Mock mode

Replies are saved examples and nothing is sent anywhere. Each button asks a question that shows one state. Typing a question with the word in quotes does the same.
