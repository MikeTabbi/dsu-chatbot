Delaware State University (widget demo page)

Chat widget demo

This page loads the widget the same way dsu.edu would: one script tag. Click Ask DSU in the bottom-right corner and ask a question, for example "Which dorms have carpeted rooms?".

The backend must be running on http://localhost:8000 and allow this page's origin (http://localhost:8080). See widget/README.md. To try the widget without a backend, open demo.html?mock=1.

Mock mode

Replies are saved examples and nothing is sent anywhere. Each button asks a question that shows one state. Typing a question with the word in quotes does the same.
